# Security Policy

This server handles OAuth tokens and access to your SendSeven account, so we
take security reports seriously.

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, email **dev@sendseven.com** with a description of the issue,
steps to reproduce, and its potential impact. We'll acknowledge your report
and work with you on a fix before any public disclosure.

## Scope

This covers the SendSeven MCP server in this repository. Vulnerabilities in
the SendSeven platform itself (`api.sendseven.com`, `app.sendseven.com`) can
be reported to the same address.
