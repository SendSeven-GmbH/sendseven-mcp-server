# SendSeven for Cursor

Connects Cursor to your SendSeven workspace through the hosted SendSeven MCP server (`https://mcp.sendseven.com/mcp`).

- **MCP server:** sign in with your SendSeven account via OAuth on first use and choose which permissions to grant.
- **Skills:** `get-started`, `triage-inbox`, `reply-across-channels`.

Messages you send reach real customers, so the assistant asks for confirmation before sending, closing or changing anything important.
